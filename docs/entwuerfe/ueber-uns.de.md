## Die Idee

Wir mögen Spiele, die man zwischendurch spielen kann: kurz reinschauen, ein paar Entscheidungen treffen und später sehen, was daraus geworden ist. Full Roast Ahead ist so ein Spiel. Du baust eine Kaffeerösterei von der ersten Pfanne bis zum Frachtschiff auf, in deinem eigenen Tempo.

## So ist das Spiel gemacht

- **Ohne Installation:** Das Spiel läuft direkt im Browser, auf dem Handy und am Computer.
- **Selbst gemacht:** Alle Texte und Grafiken sind eigens für das Spiel entstanden.
- **Sparsam mit Daten:** Keine Anmeldung, keine Analyse-Werkzeuge. Dein Spielstand bleibt in deinem Browser.
- **Faire Werbung:** Das Spiel finanziert sich durch Werbung. Belohnungen per Werbung sind freiwillig.
